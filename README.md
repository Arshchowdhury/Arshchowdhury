## What's in the portfolio

**[Portfolio_ArshWafiqKhanChowdhury](https://github.com/Arshchowdhury/Portfolio_ArshWafiqKhanChowdhury)**

### AI Agent Designs
Four industry-specific agents built on Azure OpenAI, Copilot Studio, and Power Automate across Financial Services, Aged Care, Retail, and Professional Services. Design philosophy: business problem first, governance as a first-class concern, mandatory human escalation paths.

The most complete artefact is the **[AI Governance Advisory Agent](https://github.com/Arshchowdhury/Portfolio_ArshWafiqKhanChowdhury/tree/main/Ai-Agent-Design/ai-governance-agent)** — a full consulting engagement simulation covering discovery through production deployment. Python RAG backend built directly against the Azure SDK (no LangChain), hybrid BM25 + vector search with semantic re-ranking, Microsoft Graph API audit logging to SharePoint, and a Power BI compliance dashboard.

### Consulting Case Studies
Three end-to-end engagement case studies: platform evaluation and migration, Power BI pipeline reporting, and digital intake automation. Each documents discovery, the platform decision and why, and the outcome.

### Power Platform Governance & ALM
A complete governance framework for a 220-person consulting firm — three-environment ring, solution layering, GitHub Actions CI/CD using `microsoft/powerplatform-actions`, Managed Environments with DLP, and an Entra ID-based maker access model.

### Architecture Decision Records
Six structured ADRs documenting significant technology choices across engagements — platform selection, data layer trade-offs, AI routing patterns, CI/CD tooling.
